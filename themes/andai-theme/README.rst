===========
AndAI Theme
===========

This comprehensive theme customizes the appearance and identity of Open edX for **AndAI**.

Assets and Templates:
- ``lms/static/images/logo.png``: Primary AndAI LMS navbar logo (derived from ``C:\AndAI\mediamodifier_cropped_image 1.png``).
- ``lms/static/images/logo-large.png``: High-resolution logo for high-DPI displays.
- ``lms/static/images/favicon.ico``: Browser tab icon for AndAI.
- ``lms/static/images/email-logo.png``: Transactional email header logo.
- ``cms/static/images/studio-logo.png``: Studio course authoring logo.
- ``lms/templates/header/brand.html``: LMS brand header template.
- ``lms/templates/footer.html``: Custom AndAI footer with copyright and legal links.
- ``cms/templates/widgets/header.html``: Studio navigation bar with AndAI Studio branding.
- ``lms/static/sass/partials/lms/theme/_variables.scss``: LMS brand color and typography overrides.
- ``cms/static/sass/partials/cms/theme/_variables.scss``: Studio brand color and typography overrides.
